# vedant-95.github.io

Vedant Kshirsagar's personal site: work, side projects, music, gaming, financial markets and more.

- All text lives in `content.js`. To add a new section, add an entry to `FOLDERS`.
- Icons are drawn in `icons.js`; layout in `style.css`; window behavior in `app.js`.
- No build step. Open `index.html` or serve the folder (`python3 -m http.server`).
- More detail (decisions, to-dos, how assets were made): see `HANDOFF.md`.
